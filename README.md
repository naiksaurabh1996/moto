## 📌 Overview
This Power BI dashboard provides an interactive analysis of **Moto mobile devices** across key performance indicators (KPIs), sales trends, model-wise performance, and regional insights.

---

## 🎯 Objectives
- Track **monthly and quarterly sales** performance
- Identify **best-selling Moto models**
- Analyze **regional demand** patterns
- Monitor **revenue, profit margins, and units sold**
- Provide **actionable insights** for inventory and marketing teams

---

| Metric | Value |

---

## 🔍 Key Findings
1. **Moto G Series** contributes to **52%** of total units sold.
2. **Q3 (Jul–Sep)** shows highest sales spike – **24K units**.
3. **Europe** has the lowest market penetration (12%).
4. **Moto Edge+** has highest profit per unit ($122).
5. **Online channels** account for **63%** of total sales.

---

## 📊 Dashboard Features
- Slicers: Model, Region, Quarter
- Line chart: Monthly sales trend
- Bar chart: Model-wise revenue
- Map: Regional sales distribution
- Cards: KPIs (Revenue, Units, ASP, Margin)
- Drill-through: Model details page

---

## 🛠 Tools Used
- **Power BI Desktop** (Version: Nov 2025 or later)
- **Data Source**: Internal sales database (CSV/Excel)
- **Data Cleaning**: Power Query
- **Visuals**: Custom visuals + native Power BI charts

---


## 🚀 How to Use
1. Download `Moto_Mobiles_Dashboard.pbix`
2. Open with Power BI Desktop
3. Refresh data if you have the source file
4. Interact with slicers and visuals
